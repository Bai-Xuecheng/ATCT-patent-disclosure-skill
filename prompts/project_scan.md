# 项目文档扫描（Step 2，模板版）

## 目标

从项目材料、已有交底书和参考模板中提取能够填入《专利交底书模板.docx》的内容。

## 优先级

1. 用户提供的《专利交底书模板.docx》：确定最终字段和表格结构。
2. 用户提供的已完成交底书：学习篇幅、措辞、图号、实施方式展开方式。
3. 专利点分析、技术方案、设计文档、PPT、会议纪要。
4. 源码、配置、接口文档、算法脚本。
5. 论文、专利、标准和外部公开资料。

## 提取表

扫描后形成如下材料表：

| 字段 | 需要提取的信息 |
|---|---|
| 发明名称 | 核心技术手段、对象、权利要求类型 |
| 关键词 | 3–5 个中文关键词及对应英文 |
| 检索式 | 中文/英文 AND OR 组合 |
| 相关技术检索结果 | 论文、专利、标准、公开资料 |
| 相关性分析 | 与现有技术的区别技术点 |
| 摘要 | 1 段核心方案概括 |
| 技术领域 | 所属技术领域 |
| 背景技术 | 场景、现有方案、缺陷 |
| 发明内容 | 要解决的问题、有益效果 |
| 实施方式 | 至少两个实施方式，S1-Sn 或步骤一至步骤N |
| 可替代方案 | 替代实现及优缺点，没有写无 |
| 附图 | 图1、图2……及图名 |
| 保护点 | 4–8 个核心技术特征 |

## Office 文档

如遇 `.docx` / `.pptx`：

- 读取正文、表格和图片说明；
- 对已有交底书，优先抽取“相关性分析”“摘要”“所有的实施方式”“附图”“着重保护的技术创新点”的写法；
- 不只读取纯文本，表格中的内容同样是核心材料。

## 输出

扫描完成后输出“材料提取摘要”，并进入专利点分析或字段预览。
