# 边界与输入录入（Step 1）

## 目标

收集生成《专利交底书模板.docx》所需的最小信息。信息缺失时可以用“待填写”，不得因少量文头信息缺失而中断写作。

## 需要确认的信息

1. **模板路径**：优先使用用户提供的《专利交底书模板.docx》。若未提供，提醒用户提供；若用户允许，可先生成 payload 草稿。
2. **参考样稿路径**：若用户提供多个已完成交底书，应读取其表格结构、段落密度、术语风格和附图说明方式。
3. **技术主题或项目路径**：一句话说明技术方案，或给出设计文档/代码仓库路径。
4. **文头信息**：编号、撰写人、技术问题联系人、手机、邮箱、座机。缺失项写空或“待填写”。
5. **发明类型**：方法、设备/系统、介质、模型、装置，或组合类型。
6. **附图来源**：是否已有流程图/架构图；没有则由 Agent 生成简洁流程图或先写“图1为……图”的说明。

## 默认填法

- 编号：用户未提供时留空。
- 撰写人/技术问题联系人：用户未提供时填“待填写”。
- 手机/邮箱/座机：用户未提供时留空。
- 可替代的技术方案：没有明确替代方案时写“无”。
- 代表性附图：优先选系统整体架构图或核心流程图。

## 输出给用户的确认摘要

用 4–8 行概括：

- 模板文件：...
- 参考交底书：...
- 技术主题：...
- 发明名称暂定：...
- 联系人信息：...
- 下一步：扫描材料并形成模板字段级预览。
