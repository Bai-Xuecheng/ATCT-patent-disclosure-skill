# 交底书生成前摘要预览（Step 6，模板版）

## 目的

在生成完整 DOCX 前，先按《专利交底书模板.docx》的字段展示预览，减少返工。

## 预览格式

```markdown
## 交底书字段预览

**发明名称**：...
**关键词**：中文：...；英文：...
**检索式**：中文：...；英文：...

**相关技术检索结果概括**：
- 期刊或书籍等现有技术：...
- 中国专利检索：...

**相关性分析核心区别**：...

**摘要**：...

**技术领域**：...

**背景技术主线**：
1. ...
2. ...
3. ...

**发明内容 / 要解决的问题与有益效果**：...

**实施方式安排**：
- 实施方式一：...
- 实施方式二：...
- 实施方式三：...

**附图安排**：
- 图1为...图
- 图2为...图
- 图3为...图

**着重保护的技术创新点**：
1. ...
2. ...
3. ...
```

## 预览要求

- 不使用原仓库六章标题。
- 不输出“注意事项”。
- 不把 mermaid 源码作为正文预览重点；只说明将形成哪些附图。
- 用户确认后再生成完整 payload 并填入 DOCX。
